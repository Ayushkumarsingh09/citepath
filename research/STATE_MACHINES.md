# State Machines

## Draft

Pending → Queued | Published (copy-open) | Archived  
Queued → Published | Queued (retry) | Archived

## Campaign

Active ↔ Paused (toggle); SoftDeleted

## Reddit Account Warmup

Day0 Created → BrowseOnly (D1–2) → OnePerDay (D3–4) → TwoPerDay (D5–6) → FullPace (D7+)

## Karma Milestone

Newcomer → Contributor → Trusted → Established

## Publishing Job

Queued → Claiming → Posting → Succeeded | FailedRetryable | FailedPermanent

## Scan Run

Queued → Running → Succeeded | Failed

## Subscription

Trialing → Active → PastDue → Canceled; TrialExpired pauses scanning

## Invitation

Pending → Accepted | Expired | Revoked
